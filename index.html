Fuentes y guía de actualización

Cómo actualizar el gráfico (paso a paso):
  1. Consulta las fuentes primarias de la tabla y anota el USD/GB del mes para DDR3, DDR4 y DDR5. Si una fuente da el precio de un módulo, divide entre su capacidad — p. ej. un kit de 32 GB DDR5 a $120 → $3.75/GB.
  2. En index.html, añade la etiqueta del mes nuevo al array labels (formato "Jun'26").
  3. Añade el valor del mes al final de cada array ddr3, ddr4 y ddr5 (los 4 arrays deben tener la misma longitud).
  4. Opcional: ajusta la banda del shock con SHOCK_START / SHOCK_END.
  5. git commit + git push a la rama → la web se republica sola en ~1 min.
